# How to publish this on your GitHub profile

1. On GitHub, create a NEW public repository named exactly: Balama2520
   (the repo name must match your username, or the README will not show on your profile).
2. Upload everything in this folder to that repo: README.md, the cards/ folder and the scripts/ folder.
   (SETUP.md is optional, you can leave it out.)
3. Open github.com/Balama2520. Your new profile README appears at the top.

To change any text:
- Cards: edit scripts/render_cards.py, run `python scripts/render_cards.py`, commit the new files in cards/.
- Everything else: edit README.md directly.

Before publishing, open each live link once and check it works.
