# How to publish this on your GitHub profile

## One-time setup

1. On GitHub, create a **new public repository** named exactly: `Balama2520`
   (The repo name must match your username — that's what makes the README appear on your profile page.)

2. Upload everything in this folder:
   - `README.md`
   - `cards/` — all 10 SVG cards
   - `scripts/render_cards.py`
   (SETUP.md is optional — leave it out of the repo.)

3. Open **github.com/Balama2520** — your new profile README appears at the top automatically.

---

## Editing cards

All card text lives in `scripts/render_cards.py` — edit the data there, then:

```bash
python scripts/render_cards.py        # animated (what you commit)
STATIC=1 python scripts/render_cards.py  # static final frame (for screenshots)
```

Commit the updated files in `cards/` and push.
